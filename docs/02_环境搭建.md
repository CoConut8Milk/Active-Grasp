# 02 环境搭建

目标平台：**Ubuntu 22.04 + ROS2 Humble + Gazebo Classic 11**。
Windows 用户走 WSL2 路线最省事，整个项目不需要独立显卡。

## 路线 A：WSL2（推荐，Windows 10/11）

1. 以管理员身份打开 PowerShell：

   ```powershell
   wsl --install -d Ubuntu-22.04
   wsl --set-default-version 2
   ```

2. 重启后在开始菜单打开 Ubuntu，创建用户名密码。

3. 更新系统并安装项目依赖（脚本会自动完成 ROS2 + Gazebo 安装）：

   ```bash
   cd /mnt/d/OneDrive/文档/Research/active-grasp
   bash scripts/setup_wsl2.sh
   ```

   脚本会安装 ROS2 Humble、Gazebo Classic、ros2_control、PyTorch CPU 等。
   预计 20–40 分钟，主要取决于网络。

4. **重要**：OneDrive 的 9P 文件系统在 Linux 下很慢，还容易出权限问题。
   强烈建议把项目复制到 Linux 原生目录再编译：

   ```bash
   mkdir -p ~/ros2_ws/src
   cp -r /mnt/d/OneDrive/文档/Research/active-grasp ~/ros2_ws/src/
   cd ~/ros2_ws/src/active-grasp
   bash scripts/build.sh
   ```

5. GUI 显示：Windows 11 的 WSLg 开箱即用；Windows 10 需要装 VcXsrv 并把
   `DISPLAY` 指向 Windows 主机（见 docs/06）。

## 路线 B：原生 Ubuntu 22.04

同路线 A，跳过 WSL 安装步骤，直接执行 `bash scripts/setup_wsl2.sh`。
原生 Ubuntu 是 ROS 最稳的运行环境，磁盘和驱动允许时优先选它。

## 路线 C：Docker

适合不想动系统、只做训练的场景：

```bash
cd active-grasp
docker compose -f docker/compose.yaml build
docker compose -f docker/compose.yaml run --rm active-grasp
# 容器内
colcon build --symlink-install
source install/setup.bash
ros2 launch ag_agent train.launch.py   # 无头训练无需 X
```

GUI 演示需要 X server，详见 docker/README.md。

## 三阶段验收

| 阶段 | 命令 | 通过标准 |
|---|---|---|
| 环境 | `ros2 pkg list \| grep -E "gazebo\|controller"` | 能列出相关包 |
| 编译 | `bash scripts/build.sh` | 无 error，`install/` 生成 7 个包 |
| 演示 | `bash scripts/run_demo.sh` | Gazebo 窗口出现，机械臂运动 |
