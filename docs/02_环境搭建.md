# 02 实验室电脑环境搭建（完整教程）

本教程从一台空电脑开始，带你装到「Gazebo 里机械臂能动」为止。适用于任何
一台新机器（实验室电脑、笔记本、云主机），**不需要真实机器人硬件，也不需要
独立显卡**。

> 硬性要求一句话：**Ubuntu 22.04（代号 jammy）+ ROS2 Humble + Gazebo
> Classic 11**。不支持 Ubuntu 24.04 / ROS2 Jazzy，装错版本后续会一路报错。

## 0. 先选路线（30 秒决策）

| 实验室电脑现在是什么系统 | 走哪条路线 |
|---|---|
| 已经是 Ubuntu 22.04 | [路线 A](#1-路线-a原生-ubuntu-2204推荐) |
| Windows 10 / 11 | [路线 B](#2-路线-bwindows--wsl2) |
| 不想动系统、主要做无头训练 | [路线 C](#3-路线-cdocker可选) |

机器要求：磁盘空闲 ≥ 50 GB，内存 ≥ 8 GB（16 GB 更舒服），CPU 即可。
需要 sudo 权限；实验室共用电脑请先确认管理员允许安装软件。

## 1. 路线 A：原生 Ubuntu 22.04（推荐）

原生 Ubuntu 是 ROS 最稳的运行环境。实验室电脑若可重装或已有空闲分区，优先
走这条。

### 1.1 安装系统

1. 从 <https://releases.ubuntu.com/22.04/> 下载 desktop ISO；
2. 用 Rufus（Windows）或 Ventoy 制作启动 U 盘；
3. 安装全程默认即可，**用户名用英文小写**（避免路径带中文或空格，ROS 对
   这类路径很敏感）。

### 1.2 换国内软件源（可选，国内网络建议做）

打开「设置 → 软件和更新 → Ubuntu 软件 → 下载自」，选择清华或阿里镜像。

### 1.3 把项目放进 Linux 原生目录

项目**必须**放在 Linux 原生文件系统里（`~/` 下），不要放在 U 盘挂载点或
OneDrive 同步目录——`colcon --symlink-install` 在那些文件系统上会失败或极慢。

```bash
mkdir -p ~/ros2_ws/src
# 方式一：从 GitHub 克隆（推荐，见第 4 节）
cd ~/ros2_ws/src
git clone https://github.com/<你的用户名>/active-grasp.git
# 方式二：U 盘/网盘拷贝
cp -r /media/<你>/U盘/active-grasp ~/ros2_ws/src/
```

### 1.4 一键安装全部依赖

```bash
cd ~/ros2_ws/src/active-grasp
bash scripts/setup_wsl2.sh
```

脚本分 5 步自动完成：基础工具 → 添加 ROS 软件源 → 安装 ROS2 Humble +
Gazebo Classic + ros2_control → 初始化 rosdep → 安装 Python 依赖
（numpy 固定 1.26.4、PyTorch CPU 2.0.1）。预计 20–60 分钟。

国内网络慢的话，编辑脚本开头把镜像注释取消（见脚本内说明）。

### 1.5 环境自检

```bash
bash scripts/check_env.sh
```

预期输出全部 `[OK]`（最后一条「尚未编译」是正常的）。任何 `[FAIL]` 都有
对应的包名提示，按 [06_常见问题排查](06_常见问题排查.md) 处理。

## 2. 路线 B：Windows + WSL2

WSL2 里跑的是真正的 Ubuntu 22.04，与路线 A 共用同一个安装脚本。

### 2.1 启用 WSL2 并安装 Ubuntu 22.04

以管理员身份打开 PowerShell：

```powershell
wsl --install -d Ubuntu-22.04
wsl --set-default-version 2
```

重启电脑，在开始菜单打开 Ubuntu，首次启动设置用户名密码。

### 2.2 更新系统

```bash
sudo apt update && sudo apt install -y git
```

### 2.3 把项目放进 Linux 目录（关键一步）

Windows 的 D 盘在 WSL 里是 `/mnt/d`，通过 OneDrive 访问时属于 9P 文件系统，
**编译和运行都会非常慢且容易出错**。必须把项目复制到 Linux 原生目录：

```bash
mkdir -p ~/ros2_ws/src
cp -r /mnt/d/OneDrive/文档/Research/active-grasp ~/ros2_ws/src/
```

后续开发也在 `~/ros2_ws/src/active-grasp` 里做；要同步回 OneDrive 就手动拷
回去，或走 GitHub（第 4 节，更推荐）。

### 2.4 安装依赖 + 自检

```bash
cd ~/ros2_ws/src/active-grasp
bash scripts/setup_wsl2.sh
bash scripts/check_env.sh
```

### 2.5 图形界面（GUI）配置

- **Windows 11**：WSLg 开箱即用，什么都不用配，直接 `ros2 launch` 就有窗口。
- **Windows 10**：需要 X server。装 VcXsrv 并启动（Disable access control
  勾上），然后在 Ubuntu 里执行：

  ```bash
  export DISPLAY=$(ip route | grep default | awk '{print $3}'):0
  ```

  把这行加进 `~/.bashrc` 永久生效。
- **黑屏或崩溃**：机器没有 GPU 时让 Gazebo 强制软件渲染：

  ```bash
  export LIBGL_ALWAYS_SOFTWARE=1
  ```

## 3. 路线 C：Docker（可选）

适合不想动系统、只做无头训练的场景（GUI 演示需要额外 X server）：

```bash
cd active-grasp
docker compose -f docker/compose.yaml build
docker compose -f docker/compose.yaml run --rm active-grasp
```

容器内执行：

```bash
colcon build --symlink-install
source install/setup.bash
ros2 launch ag_agent train.launch.py   # 无头训练不需要图形界面
```

## 4. 把项目带到实验室电脑（两种方式）

### 4.1 推荐：GitHub 私有仓库

在现有电脑的项目目录（已是一个 git 仓库）：

```powershell
git remote add origin https://github.com/<你的用户名>/active-grasp.git
git push -u origin main
```

实验室电脑：

```bash
mkdir -p ~/ros2_ws/src && cd ~/ros2_ws/src
git clone https://github.com/<你的用户名>/active-grasp.git
```

好处：两边代码自动同步，训练产出（CSV、checkpoint）还能推回仓库留档。

### 4.2 拷贝文件夹

用 U 盘或网盘把整个 `active-grasp` 文件夹拷到实验室电脑，再放进
`~/ros2_ws/src/`。注意 `.git` 目录也一起拷，版本管理不会断。

## 5. 编译

```bash
cd ~/ros2_ws/src/active-grasp
bash scripts/build.sh
```

预期输出：`Summary: 7 packages finished`，没有红字 error。首次编译几分钟。

> 编译不需要 rosdep 额外下载：项目只依赖 `ros-humble-desktop` 与
> `ros-humble-ros2-controllers` 系列自带的包。

## 6. 首次启动验收（三个 ready）

```bash
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch ag_bringup sim.launch.py
```

按顺序应当出现：

1. Gazebo 窗口：一张桌子、蓝色回收盒、四条低矮边界墙；
2. 机械臂出现在桌子一角，几秒后自动运动到 home 位姿；
3. 终端依次打印 `world manager ready`、`perception ready (camera
   calibrated)`、`execution ready`。

**三个 ready 全部出现 = 环境搭建成功。** 之后按
[03_快速跑通流程](03_快速跑通流程.md) 第 3 步开始手动验证和演示。

## 7. 快速故障表

| 症状 | 最可能的原因 |
|---|---|
| 脚本报「只支持 22.04」 | 系统版本不对，重装 22.04 或换 WSL2 Ubuntu-22.04 |
| apt 下载极慢 | 换国内 apt 镜像 |
| pip 报 externally-managed | pip 太新，加 `--break-system-packages` 或降级 pip |
| Gazebo 黑屏 | `export LIBGL_ALWAYS_SOFTWARE=1` |
| 编译在 OneDrive 路径失败 | 项目没放进 `~/`，回到 1.3 / 2.3 |
| 没有三个 ready | 看终端完整日志，对照 docs/06 逐项查 |

其余问题见 [06_常见问题排查](06_常见问题排查.md)。
