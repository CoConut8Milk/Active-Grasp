# 08 简历与申请材料

## 1. 简历条目（三种长度）

### 单行版（简历列表项）

> 设计并实现 Active-Grasp：一个 ROS2/Gazebo 桌面杂乱场景抓取系统，在视觉
> 推抓框架上引入不确定度驱动的主动视角选择，在 8 物体场景将清理率从 25%
> 提升到 42%（对比固定视角消融，5 随机种子，p<0.05）。

### 三段版（项目栏）

> **Active-Grasp：主动视角的视觉推抓（ROS2 + Gazebo + PyTorch）**
>
> - 构建完整仿真闭环：6-DoF 机械臂、二指夹爪、眼在手 RGB-D 相机、
>   手写 FK/数值 IK、程序化杂乱场景与域随机化。
> - 提出多视角高度图融合与三因子不确定度图（空洞/信息年龄/遮挡边缘），
>   用 DDQN 学习「抓/推/换视角」联合策略与课程学习。
> - 与无视角、随机视角、贪心策略做消融与多种子统计对比；开源代码、
>   训练曲线与实验报告。

### 面试 60 秒版

> 我的项目回答一个问题：机器人在杂乱场景里，默认视角被挡住时该怎么办。
> 我把「换视角」做成强化学习的一个动作，用不确定度图做状态和奖励，让
> 机器人学会该不该看、从哪看。和固定视角基线相比，越乱的场景提升越明显。

## 2. 诚实标注（重要）

## 3. 个人陈述（Statement of Purpose）角度

不要写「我热爱机器人」，要写问题驱动的故事：

> 大多数抓取系统假设一个固定俯视相机。但真实世界没有这么好的视角。我开始
> 问：机器人能不能学会主动寻找更好的视角？为了隔离这个问题，我在仿真里
> 复现 VPG，加入学习式视角选择，并做了系统消融。结果告诉我：主动感知的
> 价值随场景复杂度的增长而增长。这让我想研究更根本的问题——机器人如何在
> 不确定环境中主动获取信息，而不仅是反应式地执行动作。

这个叙述把项目与「具身智能 + 主动感知」的博士方向直接连接起来。

## 4. 演示视频脚本（60–90 秒）

1. 0–10s：标题 + 项目名 + 一句研究问题；
2. 10–25s：Gazebo 里机械臂归位、物体随机生成（体现域随机化）；
3. 25–45s：分屏——左侧 Gazebo 动作，右侧高度图/不确定度图；重点展示一次
   「视角动作→不确定度下降→成功抓取」的因果链；
4. 45–60s：消融对比柱状图（完整 vs 无视角）；
5. 60–90s：结尾给 GitHub 链接 + 联系邮箱。

录屏工具：OBS Studio（免费）。视频放 YouTube 非公开链接，简历里附二维码。
